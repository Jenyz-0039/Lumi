# 可颂 IP 交互展示网站

## 品牌命名规则

- **可颂**是 APP 名称，用于网站标题、产品品牌和 APP 语境。
- **露米**是原创 IP 角色名，用于角色介绍、动作、表情、场景及互动文案。
- 后续新增模块必须根据语义区分两者，不进行机械全局替换。

这是单页纵向滚动网站的基础框架阶段版本。当前只包含页面结构、独立模块组件、明确标记的素材占位、侧边章节导航和基础滚动定位逻辑。

## 本地预览

由于项目使用原生 ES Module，建议通过本地静态服务器预览，而不是直接双击 `index.html`：

```bash
node preview-server.cjs
```

如果需要临时换端口，可以使用：

```powershell
$env:PORT=4174; node preview-server.cjs
```

然后打开：<http://localhost:4173>

也可以使用任意支持静态文件的本地服务器。

## 目录说明

```text
index.html                 页面入口
styles.css                 全局样式、布局和响应式基础
src/main.js                页面组装、导航、滚动观察和事件绑定
src/data/sections.js       模块、表情、服装、场景的数据定义
src/state/store.js         预留的轻量状态管理
src/components/            可复用布局、导航、素材占位组件
src/sections/               11 个独立页面模块
```

## 当前范围

- 已完成单页 11 个模块的顺序结构。
- 已完成侧边章节导航和当前章节指示。
- 已完成基础平滑滚动定位和滚动进度显示。
- 已预留角色、表情、服装、场景和小游戏的状态字段。
- 已使用明确的“素材占位”区块，没有引入任何临时参考素材。
